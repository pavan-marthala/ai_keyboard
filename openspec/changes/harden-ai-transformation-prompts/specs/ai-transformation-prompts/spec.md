# Spec Delta

## Purpose

Defines the canonical system prompts for AtFix's text-transformation commands and the output contract they must enforce, so every platform returns only the transformed text to the user.

## ADDED Requirements

### Requirement: Output-only contract
Every canonical command prompt SHALL instruct the model to return exactly one transformed text and no additional content.

#### Scenario: Fix command response
- **WHEN** a model transforms text with the `@fix` prompt
- **THEN** the prompt explicitly forbids preambles, explanations, labels, "generated by AI" notices, and any text other than the corrected text

#### Scenario: Already-correct text
- **WHEN** the input text requires no change
- **THEN** the prompt instructs the model to return the original text unchanged without commentary

### Requirement: Per-command semantics preserved
Each prompt SHALL retain its original transformation intent while sharing the same output-only contract.

#### Scenario: Rewrite family
- **WHEN** the user runs `@rewrite`, `@professional`, or `@casual`
- **THEN** the prompts still request paraphrasing or tone changes while forbidding explanations and added information

#### Scenario: Length and translate commands
- **WHEN** the user runs `@short`, `@expand`, or `@translate`
- **THEN** the prompts still request shortening, expanding, or translating (with `{{language}}` interpolation) while returning only the result

### Requirement: Canonical source and generated consistency
The shared JSON SHALL remain the single source of truth, and committed generated artifacts SHALL match it.

#### Scenario: Prompt change propagation
- **WHEN** a prompt is changed in `shared/prompts/ai_prompts.json` and the generator is run
- **THEN** the regenerated Dart, Kotlin, Swift, and C++ artifacts contain the identical prompt text

#### Scenario: No duplicate commands
- **WHEN** prompts are updated
- **THEN** the seven canonical commands and their triggers remain unchanged and `@pro` is not introduced
