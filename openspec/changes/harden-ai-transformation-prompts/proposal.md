# Proposal: Harden AI Transformation Prompts

## Why

The canonical prompts in `shared/prompts/ai_prompts.json` already say "Return ONLY the corrected text," but in practice some model responses still append commentary such as "Generated by AI" notices, preambles, or labels. That extra text is inserted into the user's document alongside the transformation. The shared prompts are the single source of truth for all platform command definitions, so the fix belongs there first.

## What Changes

- Rewrite the `system` prompt for all seven canonical commands (`@fix`, `@rewrite`, `@professional`, `@casual`, `@short`, `@expand`, `@translate`) with an explicit output contract: return exactly one transformed text and nothing else — no preambles, suffixes, labels, "generated by AI" notices, commentary, markdown fences, or surrounding quotes.
- Keep each command's transformation semantics and the version 2 JSON schema unchanged; add no commands and no `@pro` alias.
- Regenerate and commit the five platform artifacts (Dart, Kotlin, Swift, C++ header/source) from the updated JSON so all platforms receive the stricter prompts.
- Document the output contract in `shared/prompts/README.md`.

Out of scope: runtime response sanitization on any platform, model/provider changes, and UI changes.

## Capabilities

### New Capabilities

- `ai-transformation-prompts`: The canonical system prompts for AtFix's text-transformation commands and their output contract, including how the shared definitions are regenerated into platform artifacts.

### Modified Capabilities

- None (no capabilities are registered in `openspec/specs/` yet).

## Impact

- `shared/prompts/ai_prompts.json`, `shared/prompts/README.md`
- Generated artifacts: `app/lib/features/commands/data/generated/generated_command_definitions.dart`, `app/android/app/src/main/kotlin/com/pk/atfix/generated/GeneratedCommandDefinitions.kt`, `app/macos/Runner/Generated/GeneratedCommandDefinitions.swift`, `app/windows/runner/generated/generated_command_definitions.{h,cpp}`
- `tools/command_definitions_generator/` tests (consistency check verifies generated files match the JSON)
